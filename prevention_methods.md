# ARP Spoofing Prevention Methods

1. Enable Dynamic ARP Inspection (DAI) on supported managed switches.
2. Use DHCP snooping where supported to help validate IP-to-MAC bindings.
3. Monitor unexpected changes in important IP-to-MAC mappings.
4. Use encrypted protocols such as HTTPS and SSH to protect application data.
5. Keep operating systems, routers, switches, and security software updated.
6. Use network segmentation to reduce the potential impact of an incident.
7. Use static ARP entries only where appropriate and manageable.
8. Investigate unexpected gateway MAC changes through an authorized network administrator.

## Note
No single measure prevents every ARP spoofing scenario. Select controls based on the network equipment and environment.
