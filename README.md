# Member 3 – ARP Detection

This folder contains Member 3's contribution to the team project.

## Files
- `ARP_Spoofing_Detection_Member3.ipynb` – Python notebook demonstrating baseline comparison, a normal test, a simulated suspicious test, and a final report.
- `dashboard.html` – interactive dashboard using simulated data.
- `detection_method.md` – explanation of the detection logic and test results.
- `prevention_methods.md` – suggested prevention and mitigation methods.
- `screenshots/` – add your own screenshots from the completed Colab tests.

## Important limitation
The network details in the notebook were manually recorded from Windows and entered into Google Colab. The changed MAC address and dashboard activity are simulated. This work does not perform live ARP monitoring or packet capture.
